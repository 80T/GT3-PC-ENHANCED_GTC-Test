# Gran Turismo 3 Decompiled, ported to Windows, and enhanced.
<p align="center">
  <img src="https://github.com/Silentwarior112/GT3-PC-ENHANCED/blob/main/logo.png">

Based on the `GT3 enhanced engine` from the [Gran Turismo 3 Decompilation](https://github.com/Silentwarior112/gt3-decomp).

## Features

### Display
  - Display modes: Windowed, Borderless, Exclusive Fullscreen
  - Adjustable resolution
  - Unlimited frame rate: True high frame-rate support
  - Fully dynamic aspect ratio support
  - Native Multi-monitor support
  - Enhanced 2-Player Battle: Fully dynamic screen layouts, including a Two-Monitor mode that gives each player their own screen with the full Single-Player HUD

### Graphics
  - Unmatched graphical clarity with true progressive scan rendering
  - Anti-aliasing
  - Levels-of-detail: Force the best level of detail at all times, or use the original LODs
  - Adjustable render distance
  - Adjustable Field of view

### Audio
  - Kernel Streaming Audio output mode for ultra-low latency audio, or Windows WASAPI audio output.
